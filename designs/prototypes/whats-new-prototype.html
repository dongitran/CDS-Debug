What's New in CDS Debug
Debug multiple SAP CAP services simultaneously — directly from VS Code.
🚀 v0.3.10 — Spring 2025
New Features
📦
Package Browser
Browse every npm package loaded in an active debug session as a collapsible tree. Jump directly to any source file — no more hunting through node_modules.
🔍
Package Regex Filter
Filter the package list by name with a regex. Pre-configure a default via cdsDebug.packageRegexFilter in VS Code settings — synced two-way with the UI.
🔄
Auto-reconnect
SSH tunnel reconnects automatically (up to 3 attempts with linear back-off) when a CF timeout or network blip drops it mid-session.
📸
Breakpoint Snapshots
Capture variable context at any breakpoint without pausing. Snapshots accumulate in the sidebar for post-request review. Enable in Settings → Breakpoint Snapshot Handling.
🌿
Branch Preparation
Before attaching, CDS Debug can stash local changes, check out the correct git branch, and run pnpm install && pnpm build so sources always match the remote service.
⚙️
Shared CAP Debug Config
Set cdsDebug.sharedCapDebugConfig once in VS Code user settings to share remoteRoot and orgBranchMap across all workspaces.
Bug Fixes & Improvements
  • ● Suppressed save-before-start errors — VS Code no longer tries to save unrelated open editors when the debugger attaches.
  • ● Package loading across new sessions — Package entries reload correctly when a debug session is restarted.
  • ● Generated srv outFiles path — Source maps for generated CAP server files resolve correctly from the expected output path.
  • ● Stale debug config cleanup on startup — Configs left by a force-killed VS Code session are removed on next activation.
Thank you for using CDS Debug!

v0.3.10 Latest Spring 2025
✨ New Features
  • 📦Package Browser — Browse npm packages in debug sessions as a collapsible tree; jump to any source file.
  • 🔍Package Regex Filter — Filter packages by name regex; synced with cdsDebug.packageRegexFilter VS Code setting.
  • 🔄Auto-reconnect — SSH tunnel auto-reconnects up to 3 times on unexpected drops.
  • 📸Breakpoint Snapshots — Capture variable context without pausing; review after requests complete.
  • 🌿Branch Preparation — Stash, checkout, install and build before attaching debugger.
  • ⚙️Shared CAP Debug Config — cdsDebug.sharedCapDebugConfig as a user-level fallback for all workspaces.
  • 🆕What's New panel — Shown automatically after upgrading to a new stable release.
🐛 Bug Fixes
  • 🔧Suppress save-before-start to prevent permission errors on debug launch.
  • 🔧Package entries reload correctly when a debug session is restarted.

  • 🔧Stale debug configs cleaned from launch.json on activation after force-kill.
