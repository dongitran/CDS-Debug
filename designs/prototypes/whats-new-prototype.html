What's New in CDS Debug
🚀 v0.3.60
Debug multiple SAP CAP services simultaneously — directly from VS Code.
What's New
📦
Package Browser
A new screen lets you browse every npm package loaded in an active debug session as a collapsible tree. Search by name, filter with a regex, and jump directly to any source file — no more hunting through node_modules manually.
📸
Breakpoint Snapshots
Capture the full variable context at any breakpoint without pausing execution — CDS Debug auto-continues and accumulates snapshots in the sidebar for review after the request completes. Toggle in Settings → Breakpoint Snapshot Handling.
⚙️
Shared CAP Debug Config
Set cdsDebug.sharedCapDebugConfig once in VS Code user settings to share remoteRoot and orgBranchMap across every workspace — no more copying cap-debug-config.json into each project.
🛡️
Stability & Fixes
Suppressed spurious save-before-start permission errors, retry package loading when a session restarts, and corrected source map paths for generated CAP server files.
🧭
Dynamic Remote Roots
Regex-based remoteRoot values now resolve per CF app before debugging starts, so generated attach configs can map services deployed under different remote folders such as /usr/sample-service-a.
🧩
Compatibility Refresh
Lowered the minimum VS Code engine target to 1.112 and checked the code against an older VS Code API type baseline, while keeping the existing CF sync, ESLint, and TypeScript ESLint updates.

v0.3.10 Stable Spring 2026
✨ New Features
  • 📦Package Browser — Browse npm packages in debug sessions as a collapsible tree; jump to any source file.
  • 🔍Package Regex Filter — Filter packages by name regex; synced with cdsDebug.packageRegexFilter VS Code setting.
  • 🔄Auto-reconnect — SSH tunnel auto-reconnects up to 3 times on unexpected drops.
  • 📸Breakpoint Snapshots — Capture variable context without pausing; review after requests complete.
  • 🌿Branch Preparation — Stash, checkout, install and build before attaching debugger.
  • ⚙️Shared CAP Debug Config — cdsDebug.sharedCapDebugConfig as a user-level fallback for all workspaces.
  • 🆕What's New panel — Shown automatically after upgrading to a new stable release.
🐛 Bug Fixes
  • 🔧Suppress save-before-start to prevent permission errors on debug launch.
  • 🔧Package entries reload correctly when a debug session is restarted.
  • 🔧Source maps for generated CAP server files resolve from the correct output path.
  • 🔧Stale debug configs cleaned from launch.json on activation after force-kill.
