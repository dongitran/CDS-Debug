# Prototypes

## Breakpoint Snapshot UX

File: `breakpoint-snapshot-prototype.html`

Mục đích:
- Mô phỏng flow 2 màn hình: `Debug Launcher` -> `Breakpoint Snapshots`.
- Mô phỏng UI list/detail cho breakpoint snapshots khi hit liên tục.
- Kiểm tra khả năng đọc nhanh danh sách và mở chi tiết context variables.
- Kiểm tra hành vi điều hướng quay về `Debug Launcher` bằng nút Back trong màn hình snapshot.

Cách mở nhanh:
- Mở file trực tiếp bằng browser hoặc dùng Playwright/MCP để snapshot.
